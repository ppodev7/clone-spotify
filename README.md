# 🎵 Spotify Clone

Um clone do Spotify desenvolvido com **Next.js** e **React**, focado em praticar e aprimorar habilidades de front-end. Este projeto replica a interface do Spotify com design moderno e responsivo.

## 📋 Sobre o Projeto

Este é um projeto **100% front-end** que tem como objetivo recriar a experiência visual do Spotify, incluindo:

- Interface moderna e responsiva
- Componentes reutilizáveis
- Navegação intuitiva
- Player de música funcional
- Biblioteca de músicas e playlists

## 🚀 Tecnologias Utilizadas

- **[Next.js](https://nextjs.org/)** 16.0.8 - Framework React
- **[React](https://react.dev/)** 19.2.1 - Biblioteca JavaScript
- **[Tailwind CSS](https://tailwindcss.com/)** 4 - Estilização
- **[Lucide React](https://lucide.dev/)** - Ícones modernos
- **[ESLint](https://eslint.org/)** - Linter para qualidade de código

## 📦 Instalação

1. Clone o repositório:
```bash
git clone <url-do-repositório>
cd clone-spotify/spotify
```

2. Instale as dependências:
```bash
npm install
```

3. Execute o projeto em modo de desenvolvimento:
```bash
npm run dev
```

4. Acesse no navegador:
```
http://localhost:3000
```

## 🛠️ Scripts Disponíveis

- `npm run dev` - Inicia o servidor de desenvolvimento
- `npm run build` - Cria a build de produção
- `npm run start` - Inicia o servidor de produção
- `npm run lint` - Executa o linter

- **Cores**: Paleta escura (preto, zinc) com acentos verdes
- **Tipografia**: Fontes modernas e legíveis
- **Ícones**: Lucide React para consistência visual
- **Animações**: Transições suaves e hover effects
- **Layout**: Grid e Flexbox para organização responsiva
